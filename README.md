
# 🍪 Fortune Cookies - Interactive Web Experience

A whimsical, interactive fortune cookie web app — entirely self-built from scratch, including UI/UX design, animations, and JavaScript logic. 🎉

## 🌟 About the Project

This project is a creative take on the classic fortune cookie concept. Built as a standalone web experience, it blends playful animations, vintage aesthetics, and quirky fortune messages to deliver a fun, delightful interaction.

* 🖌️ **UI/UX Design**: Custom visuals, handpicked design elements, and animation timing — all crafted manually without design libraries.
* 💻 **Code**: Written entirely from scratch using HTML, CSS (with custom animations), and vanilla JavaScript.
* 🔮 **Features**:

  * Custom fortune message generator
  * Smooth cookie cracking animation
  * Background audio trigger
  * Hidden elements that reveal with transitions

## 🖥️ Best Experience

🔸 **Optimized for Desktop/Laptop viewing** — due to the visual layout and animation scale.

🔸 **Mobile Support**: Basic mobile compatibility is included. It functions well, but some visual elements may scale imperfectly due to the intentionally stylized layout.

> This was a solo project — all visuals, logic, styling, and behavior were manually coded without frameworks.

## 🛠️ Tech Stack

* HTML5
* CSS3 (including custom keyframe animations)
* JavaScript (vanilla)
* Audio & image asset management
